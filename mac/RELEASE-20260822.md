# Mac complete release - 2026-08-22

This branch now contains the complete macOS local runtime built and verified on
2026-08-21, rather than an incremental viewer-only update.

Included:

- Five undo modes: standard, full, light (30 steps), hardcore (one step and
  random-outcome cutoff), and expert (no undo and no debug controls).
- Account password, personal save backup/restore, runtime status, LAN address,
  and diagnostics in Settings.
- The current management command, save-history viewer, Build UI, Build API
  cache, PostgreSQL runtime, and portable Apple Silicon backend.
- Full current ArkhamHorror source snapshot and the shared Chinese AVIF card
  library. Card `01000.avif` is included in this release.

The release excludes player databases, save files, logs, session keys, and
machine-specific configuration.
