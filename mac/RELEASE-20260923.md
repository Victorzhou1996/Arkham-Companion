# macOS arm64 2026.09.23.3

The local launcher and separate management app do not require Companion.
This package reuses the verified September 23 native engine and rebuilds the
latest frontend. It does not silently pull newer upstream game rules.

## Included

- Investigator card, personal token/action row and full-width skill strip are bottom-aligned. All investigator buttons occupy one right-hand column. Personal deck/discard artwork is centered.
- Global doom and spendable clues are above encounter piles, against the map edge by default, and support unlocked dragging, persistence and reset.
- Current/classic game UI selection remains fixed until changed in Settings.
- Classic BloodToken/ValueX compatibility, Carcosa openings and Empirical Hypothesis layout fixes.
- Five community starter decks with complete notes, alongside the existing two. Add missing starters without overwriting edited decks.
- Complete Chinese campaign messages including Cycle 5, shared by both UIs.
- 618 reviewed card-image changes: 299 replacements and 319 additions; 10531b retains the clearer upright existing image.
- 52 authorized music files, scenario-title mapping, manual selection, autoplay, loop and volume; separate music/voice controls.

## Repackage

Run `git lfs pull` first. Required audio and images must be real files.
From the repository root:

```sh
APP_VERSION=2026.9.23.3 RELEASE_DATE=20260923 bash mac/packaging/build-local-macos-dmg.sh
```

The script uses `mac/release/ArkhamHorror-macos-arm64` and `shared/cards` by default.
Native binaries, PostgreSQL, Nginx and both app icons are included. Player data,
session keys, database backups, deployment credentials and test saves are excluded.
Back up player data before upgrading; installation replaces runtime files and
keeps player data in its separate Application Support directory.

Source: `mac/source/ArkhamHorror`. The server branch provides the matching
Linux amd64 executable and current online-mode frontend. Windows local builds
must rebuild the frontend with `VITE_ONLINE_MODE=false` and retain their own
launcher/manager; do not copy the macOS binary.
