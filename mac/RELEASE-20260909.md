# macOS local release 2026-09-09

## Change

- Local Build decks now use **Export and open arkham.build** instead of the
  broken account-upload request.
- The action downloads arkham.build-compatible JSON and opens the official
  site, where **Import JSON** accepts the file.
- Local and LAN Build links remain available for access to the same local
  server.
- The release packager now excludes generated `client_session_key.aes` files
  and fails if one reaches the package staging tree.

## Verification

- TypeScript check and production build passed.
- 12 focused import/export tests passed.
- Headless local-runtime verification created a fresh account, exported a
  starter deck, opened `https://arkham.build/`, and imported the JSON there.
- DMG mounted successfully; both apps passed strict signature verification,
  have distinct icons, and contain no player database, dump, or generated
  client session key.
