# Mac Local 2026.09.15: Tabletop UI

Mac now ships the local game launcher and the separate management-tool launcher only. This release does not build or remove Companion.

- Baseline: Mac PR #8 / `a4252e0c7ddb6c3d78fb37ca797bbe7fd5bd414f`.

- The September 13 native macOS backend is reused without recompilation or byte changes. SHA-256: `b6ee888e6a4b0d99d5894eaab3fa2e871da322c131a6ca96552815b71a550912`.
- No later upstream rule commits, database changes, Build updates, or server deployment are included.

## Changes

Green tabletop/home theme, adjustable panels, map zoom and camera memory, overlapping hands/threats, fitted equipment, bounded interaction hints, mobile presentation, and game-load/undo-entry recovery.

Panel preferences remain browser-local and account-scoped. This build does not call the optional account-layout service or probe Companion on port 8688. Existing management tools, starter decks, card images, save modes, and native application paths are retained.

## Frontend build

From `mac/source/ArkhamHorror/frontend`:

```sh
npm ci
npm test
npm run tc
VITE_ONLINE_MODE=false VITE_LOCAL_LAYOUT_ONLY=true VITE_DISABLE_COMPANION=true VITE_API_HOST='' VITE_ASSET_HOST='' VITE_CARD_IMAGE_CDN_HOST='' npm run build
```

Use the existing Mac packaging flow and Mac native runtime, never Linux/Windows binaries or the online-mode frontend. Keep the bundled Chinese card library when replacing frontend resources. Runtime data directories must contain only the clean setup schema, not user data.
