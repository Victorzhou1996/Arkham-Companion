# Arkham Server Update - 2026-07-30

## Included

- Extended three-state response controls to eligible player-controlled cards,
  including neutral/story assets, customized Fast cards, attachments, proxy
  abilities, and temporary Fast play windows.
- Kept public cards, deck-search results, off-zone cards, forced abilities, and
  internal actions outside the response-control UI.
- Restored the multi-row chaos-token selector used by Unrelenting.
- Added the card-image fallback order: Companion, CDN, Chinese server image,
  then English server image.
- Added touch pinch-to-zoom and pan support to the Scarlet Keys world map while
  preserving desktop mouse behavior.
- Included the current narration, achievement, and response-window ownership
  fixes from the preceding validated build.
