# Mac local release - 2026-08-24

This branch contains the runtime used by the verified
`Arkham-Horror-Local-App-macOS-arm64-20260823.1.dmg` package.

## Package changes

- Installs two normal Applications entries: `Arkham Horror Local.app` and
  `Arkham Horror 管理工具.app`.
- The manager opens the packaged management command after the local runtime has
  been initialized once.
- Runtime files are installed under the current user's Application Support
  directory; no build-machine absolute path is embedded in the launchers.
- The DMG still contains the full offline game, Build interface, database
  runtime, Chinese AVIF card library, five undo modes, and save-history viewer.

## Reproducible packaging

After fetching Git LFS objects, reproduce this package with:

```bash
RELEASE_DATE=20260823.1 APP_VERSION=1.0.1 \
  bash mac/packaging/build-local-macos-dmg.sh
```

The script packages `mac/release/ArkhamHorror-macos-arm64` and `shared/cards`
without rebuilding the Haskell backend.

Verified DMG SHA-256:
`549be5bf293f80c02bd516d67397aedecee1a464533ad89a099756884effb5c8`

The release excludes player databases, save files, logs, session keys, and
machine-specific configuration.
