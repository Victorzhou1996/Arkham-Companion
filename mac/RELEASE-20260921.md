## Build Profiles

From `frontend`, install the lockfile dependencies, run `npm test` and `npm run tc`, then build:

```sh
# Mac local launcher and local Windows runtime frontend
VITE_ONLINE_MODE=false VITE_LOCAL_LAYOUT_ONLY=true VITE_DISABLE_COMPANION=true VITE_API_HOST='' VITE_ASSET_HOST='' VITE_CARD_IMAGE_CDN_HOST='' npm run build

# Hosted server with its existing account-layout/registration/archive sidecar
VITE_ONLINE_MODE=true VITE_LOCAL_LAYOUT_ONLY=false VITE_DISABLE_COMPANION=true VITE_API_HOST='' VITE_ASSET_HOST='' VITE_CARD_IMAGE_CDN_HOST='' npm run build
```

Do not run both into the same release directory without preserving the selected output. `npm run build` prepares the pinned classic bundle and compressed assets. The module entry is now `app-*.js`, not necessarily `index-*.js`; package the entire output and follow `index.html`, never select a bundle by an old filename prefix.

Keep `legacy-ui-v20260826.3/prepared` as the build input. `prepare-legacy-ui.cjs` verifies exact hooks and generates `public/legacy-ui-20260921.1`. Do not hand-edit the generated compressed bundle. Include `legacy-custom-cards-v20260921.js`, its lazy chunks, local portraits, homebrew artwork and the existing Chinese/English card libraries. Build's matching header is `build-theme/archive-navigation-v20260921.css`; include it after the existing Build theme link.
