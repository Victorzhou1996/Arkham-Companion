## Building

Use the included source snapshot, not the older Server branch frontend. Run `git lfs pull` before building or packaging; audio and image assets require LFS contents. The frontend preparation step rebuilds the pinned classic compatibility bundle from `legacy-ui-v20260826.3/prepared`.

Before deployment, run `python3 server/packaging/verify-server-release.py`.
`RELEASE-MANIFEST.json` and `SOURCE-MANIFEST.json` describe exact published bytes.
For Windows local packages, build with `VITE_ONLINE_MODE=false`; do not reuse
the online-mode frontend directly. The backend is Linux amd64 for Linux/WSL.
