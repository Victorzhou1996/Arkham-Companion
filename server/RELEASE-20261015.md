本次发布 Windows/WSL2、Linux amd64 完整包及与它们对应的源码，供后续原生 Mac 重编译。不是全平台发布，也不会自动升级 Kaho/Online；Mac 和 Companion 分支未修改。

## 更新内容

- 新旧界面与 Build 共享六项导航、绿色公共页面及统一设置入口；保留自制卡管理和原生规则编辑器。旧设置书签重定向至 `/build/settings`。

- 修复原生游戏列表的个人存档导出兼容；补全肉体/精神创伤选择中文，并优化窄屏布局。
- 延续10月9日规则引擎、五套社区预组、暗物质416卡面/1306字段汉化及920处卡图共享存储。后端与原始卡图未在本版变更。

完整文件、校验值及元数据见 [包目录](packages/README.md)。当前游戏版本 `2026.10.15.1-shared-ui`，固定上游 `f6ed09bec346ebc505ade739d34a7aea3305fa5c`，汉化 `zh-20261009-r9`。

## 安装与升级

Windows需WSL2；Linux需amd64、Ubuntu24.04/glibc≥2.39。下载并核对 `.sha256`，解压到新目录。已有安装先正常停服并验证备份，保留旧版和外置数据，再按包内升级说明操作；禁止覆盖运行目录或向旧数据库导入空库 `setup.sql`。

所有卡图URL保持不变。相同内容可能采用硬链接，未来修改必须用独立临时文件加原子替换，不能就地覆盖共享实体。普通本地模式禁用Companion；不含真实账号、存档、密钥或线上配置。
