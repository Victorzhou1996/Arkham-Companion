## 获取与强制校验

```sh
git clone --branch Server --single-branch https://github.com/Victorzhou1996/Arkham-Companion.git
cd Arkham-Companion
git lfs install
git lfs pull
python3 server/packaging/verify-server-release.py
```

默认验证必须拿到真正的LFS文件，不能用几行指针文件充当图片或后端。`--allow-lfs-pointers` 仅供源码元数据审计，不代表可部署。后端/Build/前端/Sidecar不匹配或前端混入旧文件会拒绝验证。旧运营站材料打包脚本已加入此校验并使用本发布说明；它仍不是一键安装器，不含用户数据和实例配置。
