# Server package - 2026-08-24

This branch contains the runtime used by the verified
`Arkham-Horror-Server-Linux-amd64-20260823.tar.gz` package.

Included:

- Linux amd64 backend, frontend, Build assets, sidecar services, deployment
  examples, and save-history viewer.
- Five undo modes: standard, full, light, hardcore, and expert.
- Account management, personal save backup and restore, diagnostics, LAN
  address display, and Build bulk import/export tools.
- Current Chinese AVIF cards and the two starter decks for new accounts.

After fetching Git LFS objects, reproduce this package with:

```bash
RELEASE_DATE=20260823 bash server/packaging/build-server-package.sh
```

This creates a clean Linux package without rebuilding the Haskell backend.
