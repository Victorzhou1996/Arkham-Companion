# 给 AI 的部署任务模板

请基于**本文件夹已编译的 v20260924.1 包**部署，不要重新下载上游、不要替换为其他 Docker 镜像。先完整阅读 README.md、UPDATE.md，再检查实际目标服务器。不要沿用制作者机器或其线上服务器的路径、IP、密钥、账号和配置。

用户需提供：目标服务器连接方式、是否全新实例、域名/证书情况、安装目录、持久数据目录、允许使用的端口、允许停机的时间。不知道的项目可先检测；不得公开密码/私钥/Token。

执行顺序：

1. 只读检测 Linux 架构、glibc、Python、systemd、磁盘/内存、端口和已有服务。只支持本包要求的 x86-64/glibc，不要替换系统 libc。
2. 检查 tar.gz 的 SHA-256，解压后校验 SHA256SUMS，确认包内无存档/密钥。
3. 向用户说明实际实例名、运行用户、目录、端口、数据备份位置、变更范围与回滚办法。发现已有实例时，禁止直接运行新装脚本或覆盖其配置。
4. 新装可使用 install-service.sh；默认仅绑定 127.0.0.1，非 root 运行，实例秘密首次随机生成。数据放在应用目录外。
5. 配置专用域名 HTTPS 反向代理，检查 WebSocket。保留其他站点；nginx -t 成功才 reload，不修改不相关服务。除 80/443 外不要开放本包内部端口。
6. 用独立测试账号验证注册、登录、存档、Build、中文卡图、操作与刷新、多人同步、按账号布局保存。不要用真实玩家存档做破坏性测试。
7. 完成后报告实际版本、目录、服务/端口、健康与功能验证、备份恢复入口、未验证项。不要显示密钥内容。

已有服务器更新：遵循 UPDATE.md，备份先行，切换应用代码时保留外部数据库/配置/密钥，不自动恢复数据库。备份可能含个人数据，不能给普通用户分发。

本包的基础自托管模式不含邮件验证、Bug 工单/归档 Sidecar。若用户要这些公网运营功能，应另行规划邮件供应商、认证、数据库最小权限和迁移，不能悄悄启用或使用制作者服务器的凭据。
