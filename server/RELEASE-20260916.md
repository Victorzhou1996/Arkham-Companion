## 获取与验证

```sh
git clone --branch Server --single-branch https://github.com/Victorzhou1996/Arkham-Companion.git
cd Arkham-Companion
git lfs install
git lfs pull
python3 server/packaging/verify-server-release.py
```

必须拿到真实 LFS 文件；几行指针不能用于部署。GitHub 网页的普通 ZIP 下载不保证包含 LFS 大文件，请优先使用上述方式。

Linux 发布材料可用 `bash server/packaging/build-server-package.sh` 生成。这是运营站部署材料，不是预配置的一键安装包，数据库、运行依赖和实例密钥仍需按 [AI 部署指南](AI-DEPLOYMENT.md) 配置。安装、启动、停止、备份和恢复工具保持在 `server/linux/self-hosted/`。

普通独立自托管仍须以 `VITE_ONLINE_MODE=false` 构建，不能直接使用这里的 online 前端替换普通包。源码位于 `server/source/ArkhamHorror/frontend/`；构建后还须保留已有公共卡图、`/cards/` 数据、Build 和 `legacy-ui-20260826.3/` 静态文件。旧 UI 的 94 份静态文件及溯源清单位于 `server/source/ArkhamHorror/legacy-ui-v20260826.3/`，不含其 Windows 程序或数据。
