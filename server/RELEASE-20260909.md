# Server release 2026-09-09

## Change

- Embedded Build decks now use **Export and open arkham.build** instead of the
  invalid account-upload request.
- The action downloads arkham.build-compatible JSON and opens the official
  site, where **Import JSON** accepts the file.
- Local and LAN Build links remain available; game backend behavior and the
  player database schema are unchanged.

## Verification

- TypeScript check and production build passed.
- 12 focused import/export tests passed.
- Headless local-runtime verification created a fresh account, exported a
  starter deck, opened `https://arkham.build/`, and imported the JSON there.
- This is a Build static-resource update only; no backend binary or database
  migration is required.
