# Windows local update — 2026-08-20

This update adds a deliberately limited authenticated web management page and keeps machine-wide administration in the external Windows manager.

## In-browser self-service

- Change the signed-in user's password after confirming the current password.
- Back up and restore that user's games and saved decks as JSON.
- View package version, service health, and the verified Windows LAN address.
- Download a browser/static-resource diagnostic report without passwords or login tokens.
- Open the integrated Build bulk deck tool.

## Build bulk deck workflow

- Extract multiple arkham.build and ArkhamDB links from pasted text.
- Import multiple JSON files, including individual decks, batch bundles, and the deck section of a personal backup.
- Skip duplicate deck contents by default and report per-item results.
- Export one deck as JSON or select several saved decks and export a reusable JSON bundle.

## External Windows manager

- Start, stop, restart, and inspect local services.
- Repair blank-page/MIME frontend problems and Windows-to-WSL LAN access.
- Configure the frontend port and show the verified `192.168.x.x` address.
- Create/restore whole-database backups, import SQL, inspect backup history, and reset the database.
- List/delete local accounts and reset an account password through the API's BCrypt password-reset path.
- Export a diagnostic ZIP that intentionally omits passwords and authentication tokens.

The Windows runtime layer is stored under `server/windows`. The web page does not expose service control, whole-database operations, or cross-user administration.
