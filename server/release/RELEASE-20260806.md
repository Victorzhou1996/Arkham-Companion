# Server Release 2026-08-06

This snapshot matches the build validated locally and deployed to the unkai
server on 2026-08-06. The online server was not modified by this release.

## Changes

- Synced the maintained rules engine with the selected low-risk upstream fixes
  and current The Drowned City development content.
- Added Chinese, searchable card-name choices for Foresight.
- Restored and extended Chinese scenario text, including recent Cycle 5, 6, 7,
  and 9 corrections.
- Preserved the three-state response controls, per-zone response preferences,
  narration menu, achievement fixes, multi-row chaos-token selector, and card
  image fallback order from the preceding releases.
- Fixed the packaged Build route and refreshed the embedded deck builder.
- Updated the one-command manual rebuild workflow and Chinese rebuild guide.
- Added the missing shared `01000.avif` card image. The remaining shared card
  library is byte-for-byte identical to the validated local package.

## Windows Packaging Handoff

Start from `server/source/ArkhamHorror/` for a native Windows build. The
prebuilt Linux backend cannot run on Windows, but `server/release/frontend-dist/`,
`server/release/build/`, and `shared/cards/` can be reused directly. Build the
backend for Windows, package a Windows PostgreSQL/runtime configuration, then
verify the root game page, `/build/`, WebSocket play, saves, and local card
images on a clean Windows installation.
