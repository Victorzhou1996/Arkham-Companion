# Server Release 2026-07-30

This snapshot matches the frontend validated on the Mac local deployment and
the unkai server. The online server was not modified.

## Changes

- Expanded three-state response controls to eligible player-controlled assets,
  story/neutral cards, customized Fast cards, attachments, proxy abilities, and
  temporary Fast play windows.
- Excluded public cards, deck searches, off-zone cards, forced abilities, and
  internal actions from response controls.
- Restored the multi-row chaos-token selector for Unrelenting.
- Added the card-image fallback order: Companion, CDN, Chinese server image,
  then English server image.
- Added touch pinch-to-zoom and pan support to the Scarlet Keys world map.
- Included the current narration, achievement, and response-window ownership
  fixes from the preceding validated build.
