# Server Release 2026-08-07

This snapshot matches the build validated locally and deployed to the unkai
server on 2026-08-07. The online server was not modified by this release.

## Changes

- Every newly registered account receives two prebuilt decks copied from:
  - `https://arkham.build/deck/view/qewhl3Do4yFlzop`
  - `https://arkham.build/deck/view/DYKly6vcYWthFOi`
- The decks are displayed as `预组卡组 间谍（请看卡组笔记）` and
  `预组卡组 马克（请看卡组笔记）`.
- The starter decks include their main deck, sideboard, taboo selection,
  customization choices, source link, and Chinese notes.
- Existing accounts are unchanged; the starter decks are created only during
  future registrations.
- Completed-campaign decks are available in the interlude upgrade selector.
- Final physical and mental trauma is written to the completed deck and restored
  when it is used to begin a later campaign.
- Build deck conversion preserves deck notes when a campaign branch is created.
- The server sidecar and its least-privilege database grant are included so
  deployments that route registration through the sidecar behave identically.
