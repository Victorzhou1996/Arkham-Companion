# Server source and frontend snapshot - 2026-08-25

This branch contains the current Arkham Companion source snapshot and the
verified game frontend for the next Windows and Linux packages.

Run `git lfs pull` after cloning so the card images and bundled Linux binary are
materialized instead of remaining as Git LFS pointer files.

Included:

- Source commit `bed34d7d3e` under `server/source/ArkhamHorror`.
- Complete Chinese localization for all standalone scenarios, with the existing
  The Drowned City localization preserved.
- Current selected upstream rule and content fixes.
- Existing local features, including five undo modes, response controls,
  narration, management tools, Build bulk import/export, starter decks, and
  image fallbacks.
- The verified production frontend under `server/release/frontend-dist`.
- Windows package overrides and manager files under `server/windows`.

Verification completed for this snapshot:

- Frontend tests: 29/29 passed.
- TypeScript/Vue type check: passed.
- Production frontend build: passed.
- All 144 Chinese locale JSON files parsed successfully.
- No missing Chinese locale files or leaf keys were found.

The bundled `server/release/bin/arkham-api` is still the previously verified
2026-08-23 Linux x86-64 binary. It was intentionally not replaced by the macOS
arm64 executable. Rebuild the backend from `server/source/ArkhamHorror` before
packaging Windows or before publishing the new backend behavior on Linux.

Databases, player saves, credentials, session keys, logs, and server backups are
not included.
